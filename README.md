## Main projects

### [elora-chat](https://github.com/hpwn/elora-chat)
Real-time multi-platform chat overlay for Twitch, YouTube, and Kick. Written in Go, runs in Docker, delivers messages over WebSockets, persists in SQLite. Three active client deployments across Twitch Partners and Affiliates - peak load around 500-600 concurrent connections across platforms. Self-hosted, environment-driven config, with a self-hosted Tailscale control plane (Headscale) for the mesh networking layer.
