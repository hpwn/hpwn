Real-time multi-platform chat overlay for Twitch, YouTube, and Kick. Written in Go, runs in Docker, delivers messages over WebSockets, persists in SQLite. Self-hosted, environment-driven config, with a self-hosted Tailscale control plane (Headscale) for the mesh networking layer.
